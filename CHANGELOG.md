# Изменения Dokvi

## 3.0.0

Подготовка проекта к публикации на GitHub под новым номером версии. Основа — 2.7.19; поведение приложения, дизайн и формат сохранённых сессий не изменены.

- Обновлён README: английская основная версия и полный русский перевод, загрузка, первый запуск, возможности, сочетания клавиш и требования.
- Добавлены инструкция экспорта Markdown в PDF и материалы для оформления репозитория и анонсов.
- Команды разработки и проверки вынесены в `docs/development.md`.
- Добавлена инструкция публикации переносимого выпуска и упаковка публичных исходников без локальных QA-данных.
- Номер 3.0.0 указан в интерфейсе, метаданных Windows и имени EXE.

Сохранены исправления 2.7.19: после отмены закрытия фокус и курсор возвращаются в редактор; Enter после крестика окна и «Отмена» вставляет новую строку.

Версии 2.x и 3.x используют один локальный профиль. Перед заменой EXE закройте предыдущую версию. Установщик не входит в выпуск. EXE не подписан. Масштабы Windows 125/150/200% остаются для проверки на другом ПК.

Этот номер версии не означает повторного полного прогона всех функций. Проверки, выполненные для 3.0.0, описаны в [отчёте подготовки](docs/release-checks-3.0.0.md).
