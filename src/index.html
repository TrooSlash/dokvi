Справка

Открыть или создать файл

«+» открывает файлы, «Создать» создаёт новый документ. Можно также перетащить файлы в окно. Каждый откроется в своей вкладке.

Сохранить изменения

Ctrl S сохраняет файл. Для нового документа нужно выбрать имя и папку. Точка на вкладке означает, что есть несохранённые изменения. «Сохранить как…» записывает файл под другим именем или в другой папке, в кодировке UTF-8.

При закрытии изменённого документа можно сохранить правки, отбросить их или отменить закрытие. Новый пустой документ закрывается без вопроса. При необходимости его тоже можно сохранить через Ctrl S.

Восстановить работу после закрытия

При запуске Dokvi возвращает открытые вкладки, место чтения и несохранённый текст из резервной копии. Она записывается отдельно от исходного файла. Чтобы обновить сам файл, нажмите Ctrl S.

При сбое последние секунды ввода могут потеряться. «Не сохранять» отбрасывает правки; вкладки, которые вы закрыли сами, не восстанавливаются.

Редактировать и читать

Ctrl E переключает чтение и редактор: слева — Markdown, справа — результат. Предпросмотр обновляется при вводе, прокрутка панелей связана. Их ширину можно менять, перетаскивая границу. Двойной щелчок по границе возвращает исходные пропорции.

В меню «⋯» есть режим «Только исходник» и переключение темы. В Aa можно выбрать размер шрифта, ширину и положение текста при чтении.

Форматирование текста

Tab добавляет пробелы до следующей позиции с шагом 4. Выделенные строки сдвигаются вместе. Shift+Tab убирает отступ. Чтобы выйти из редактора к кнопкам, нажмите Escape, затем Tab.

Для форматирования выделите текст и нажмите кнопку в центре верхней панели. Заголовки и списки применяются к выбранным строкам. Повторное нажатие B, I или S снимает оформление. После вставки ссылки введите адрес в выделенное место. Ctrl Z отменяет действие.

Язык интерфейса

Выберите язык в «⋯ → Язык / Language». «Как в системе» включает русский для русскоязычной Windows, иначе английский. Ручной выбор сохраняется после перезапуска.

Вкладки и сочетания клавиш

Если вкладок много, листайте полосу колёсиком или стрелками. Стрелка вниз открывает список вкладок с поиском по имени и пути.

Форматы и отображение

Открываются .md, .markdown, .mdown, .mkd и .txt размером до 20 МБ.

Поддерживаются заголовки, выделение текста, ссылки, изображения, списки, цитаты, таблицы, задачи, код, сноски, определения, индексы и emoji. Формулы LaTeX и диаграммы Mermaid работают без интернета. Есть блоки NOTE, TIP, IMPORTANT, WARNING и CAUTION.

Enter переносит текст на новую строку в предпросмотре. Пустая строка отделяет абзацы. Дополнительные пустые строки сохраняют расстояние между ними.

Другие программы Markdown могут объединять обычные переносы строк. Dokvi показывает их как новые строки, сохраняя исходный текст файла.

Изображения из интернета требуют подключения. Локальные картинки загружаются из папки документа и её подпапок; новый документ сначала нужно сохранить в нужную папку.

Некоторые расширения Obsidian и MDX могут отображаться обычным текстом. Скрипты, iframe и встроенные стили HTML не выполняются.

Если вместо букв видны непонятные символы, проверьте «⋯ → Кодировка». Чтобы открывать .md двойным щелчком, выберите Dokvi через «⋯ → Приложение по умолчанию…».
