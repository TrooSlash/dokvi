# Сайт Dokvi на GitHub Pages

- English: <https://trooslash.github.io/dokvi/>
- Русский: <https://trooslash.github.io/dokvi/ru/>
- Sitemap: <https://trooslash.github.io/dokvi/sitemap.xml>

## Устройство

`scripts/build-site.mjs` собирает обе языковые страницы из одного шаблона. Тексты находятся в `site/content.json`, стили — в `site/style.css`, сведения об опубликованном EXE — в `site/release.json`. Иконка и снимки копируются из существующих `src/icon.svg` и `docs/images`.

На выходе обычный HTML и CSS, без клиентского JavaScript, внешних шрифтов и дополнительных npm-зависимостей. JSON-LD описывает приложение и не исполняет код. Смена языка — переход по обычной ссылке; язык не перенаправляется автоматически.

## Проверить локально

Из корня репозитория, с установленным Node.js:

```powershell
node scripts/build-site.mjs
python -m http.server 4173 --bind 127.0.0.1 --directory dist/site
```

Откройте `http://127.0.0.1:4173/` и `http://127.0.0.1:4173/ru/`. Python нужен только для этого варианта локального просмотра. Сборка сайта не собирает приложение или установщик.

GitHub Actions публикует только `dist/site` при изменении файлов сайта в `main`. Workflow также можно запустить вручную. Используется стандартное окружение `github-pages`; версии Actions закреплены SHA.

## При следующем выпуске

Сначала опубликуйте EXE в GitHub Release, затем обновите `site/release.json`: версию, прямую ссылку загрузки, страницу релиза и точный размер файла в байтах. Обе страницы получат одинаковые сведения при сборке. Сведения о сайте отделены от версии разрабатываемого приложения, чтобы кнопка не начала вести на ещё не выпущенный EXE.

Перед публикацией проверьте кнопку загрузки, переключение EN/RU, раскрытие режима чтения, клавиатурный фокус и отсутствие горизонтальной прокрутки на телефоне. В браузере без JavaScript содержимое и ссылки должны оставаться доступными.

## Индексация

У каждого языка собственные `title`, description, `lang`, canonical и взаимные `hreflang`. Английская страница указана как `x-default`. Обе страницы включены в Sitemap. Настроены Open Graph и метаданные карточки ссылки; отзывы и рейтинги не добавлялись. [Рекомендации Google для языковых версий](https://developers.google.com/search/docs/specialty/international/localized-versions).

После публикации владелец может добавить префикс `https://trooslash.github.io/dokvi/` в Google Search Console и сайт в Яндекс Вебмастер, подтвердить права предложенным сервисом способом и отправить `https://trooslash.github.io/dokvi/sitemap.xml`. Код подтверждения выдаёт соответствующий сервис; в проект не добавлены выдуманные или чужие коды. [Sitemap в Яндекс Вебмастере](https://www.yandex.ru/support/webmaster/ru/indexing-options/sitemap).

Для проектного адреса `/dokvi/` файл `/dokvi/robots.txt` не управляет всем хостом. Роботы проверяют `https://trooslash.github.io/robots.txt`; сайт проекта его не подменяет. Индексацию разрешает стандартное поведение при отсутствии запрета. [Область действия robots.txt](https://developers.google.com/search/docs/crawling-indexing/robots/intro).

Размещение сайта и Sitemap не гарантирует срок появления в поиске или конкретные позиции. Отправка в кабинеты вебмастеров и фактическая индексация проверяются отдельно от успешного развёртывания GitHub Pages.
