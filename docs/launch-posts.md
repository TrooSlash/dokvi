# Анонсы Dokvi 3.0.0

Черновики для автора. Публиковать после загрузки `Dokvi-3.0.0.exe` в [Releases](https://github.com/TrooSlash/Dokvi/releases) и проверки скачивания. Ничего из этого файла автоматически не отправляется.

## Русский анонс

**Dokvi 3.0.0: читалка и редактор Markdown для Windows**

Выложил Dokvi для работы с файлами `.md`. Документ можно читать с форматированием или открыть исходник и предпросмотр рядом. При прокрутке обе панели показывают одно место текста, а кнопки сверху помогают оформить выделение.

Есть вкладки, восстановление черновиков, формулы LaTeX, диаграммы Mermaid и экспорт в PDF. Интерфейс на русском и английском, со светлой и тёмной темами.

EXE занимает около 3,4 МиБ. Для запуска нужны Windows 10 версии 2004+ или Windows 11, x64, .NET Framework 4.8 и WebView2 Runtime. Сама программа запускается из папки; выпуск пока без установщика и цифровой подписи. Исходники под MIT.

[Скачать Dokvi и посмотреть исходники](https://github.com/TrooSlash/Dokvi).

Попробуйте открыть свой Markdown-документ. Если что-то отображается неправильно, пригодятся небольшой пример файла и версия Windows в [Issues](https://github.com/TrooSlash/Dokvi/issues).

## English announcement

**Dokvi 3.0.0: a Markdown reader and editor for Windows**

I've released Dokvi for reading and editing `.md` files on Windows. You can read a formatted document or edit its source beside a live preview. Scrolling keeps the two panes at the same place, and formatting buttons work on selected text.

It has tabs, draft recovery, LaTeX math, Mermaid diagrams, and PDF export. The interface supports English and Russian, with light and dark themes.

The EXE is about 3.4 MiB. It requires Windows 10 version 2004+ or Windows 11, x64, .NET Framework 4.8, and WebView2 Runtime. The app runs from a folder; this release has no installer or publisher signature. The source is MIT-licensed.

[Download Dokvi and browse the source](https://github.com/TrooSlash/Dokvi).

Try it with one of your Markdown files. If the rendering looks wrong, a small example and your Windows version in [Issues](https://github.com/TrooSlash/Dokvi/issues) would help reproduce it.
