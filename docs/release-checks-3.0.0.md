# Подготовка Dokvi 3.0.0

Дата: 11 ноября 2026 года. База приложения: 2.7.19.

В 3.0.0 изменены номер версии, README, документация и упаковка публичных исходников. Логика чтения, редактирования, сохранения и восстановления не менялась. Профиль 2.x сохранён.

Среда: Windows 10 Pro 19045 x64, 96 DPI, Node.js 26.13.0 и npm 11.20.0.

| Проверка | Результат |
| --- | --- |
| `npm run build` | EXE собран |
| `npm run test:unit` | 26/26 |
| `npm test` | 31/31 группа основных сценариев |
| `npm run test:quality` | 20/20, включая загрузку снимка и README в окнах 1120 и 620 пикселей |
| Сборка в отдельной копии публичного архива | `npm ci`, `npm run build` и публичная упаковка выполнены без локальных SDK и `node_modules` из рабочей папки |

После обновления версии в Win32-манифесте оболочка пересобрана в обеих копиях. Метаданные Windows и манифест содержат `3.0.0.0`; интерфейс получает `3.0.0` из `package.json`. Размер EXE — 3 566 080 байт, как у 2.7.19. Основные тесты выполнены до последнего изменения номера в манифесте; программная логика после них не менялась.

Основной набор проверяет файлы и кодировки, вкладки, редактирование, сохранение, форматирование, предпросмотр, поиск, справку, RU/EN и базовый экспорт PDF. 31 группа не означает полное покрытие кода. Все документы и профили в этом проходе тестовые.

README просмотрен в Dokvi при двух ширинах: скриншот загружается, текст и ссылки помещаются. Проверены локальные ссылки документации и содержимое архива исходников. Отображение непосредственно на GitHub, в том числе в тёмной теме GitHub, до публикации не проверялось.

Это отчёт подготовки публикации, а не повторная полная приёмка всех функций. Нативные масштабы Windows 125/150/200% остаются для другого ПК. Установщик не собирался, цифровая подпись не добавлялась.

README использует существующий снимок приложения и обычную разметку GitHub. Новые изображения и декоративные элементы не создавались. Ссылки Releases и Issues рассчитаны на `TrooSlash/Dokvi`; публикация репозитория и выпуска выполняется отдельно.

Для переноса исходников используйте публичный архив из `host/package.ps1 -PublicSource`. Он не содержит локальные журналы, тестовые профили и каталоги инструментов. Прежние материалы QA остаются в рабочей копии; их отсутствие в публичном архиве не меняет историю проверок.

После перевода основного README на английский повторно выполнены 20 проверок качества. Его отображение просмотрено в Dokvi при ширинах 1120 и 620 пикселей; русская версия и новые инструкции проверены по исходной разметке и локальным ссылкам. EXE остался прежним. Это проверка документации, а не новый полный прогон приложения или подтверждение поисковых позиций.
