# Публикация Dokvi 3.0.0

Репозиторий: `TrooSlash/Dokvi`. Эта инструкция подготавливает переносимый выпуск без установщика. Создание GitHub-репозитория и публикация Release выполняются отдельно.

## Репозиторий

1. Распакуйте `Dokvi-3.0.0-source.zip` в отдельную папку.
2. Разместите **содержимое** архива в корне `TrooSlash/Dokvi`: `README.md`, `package.json`, `host`, `src` и остальные папки должны лежать на верхнем уровне.
3. Убедитесь, что загружены `docs/README.ru.md`, `docs/images` и `ui/THIRD-PARTY-NOTICES.txt`: основной README на английском ссылается на них относительными ссылками.
4. Откройте README на GitHub и проверьте изображения, переходы к руководству и документации. Ссылки Releases и Issues рассчитаны на этот репозиторий.

Исходники не содержат готовый EXE. Не добавляйте в Git `node_modules`, `tools`, `dist`, локальные тестовые профили и журналы: они исключены через `.gitignore` и из публичного архива.

Для About и Topics используйте [готовые настройки репозитория](discovery.md). Там же находятся порядок анонсов и учёт первых загрузок. [Тексты анонсов на русском и английском](launch-posts.md) рассчитаны на уже опубликованный Release.

## Перед выпуском

- [ ] Выполнить команды сборки и нужные наборы из [инструкции разработчика](development.md).
- [ ] Проверить, что EXE и «Справка → О программе» показывают 3.0.0.
- [ ] Сопоставить фактические результаты с [заметками выпуска](../CHANGELOG.md); старые проверки не обозначать как новые.
- [ ] Масштабы Windows 125/150/200% проверить на другом ПК либо явно оставить ограничением выпуска.
- [ ] Проверить ссылки README и перечисленные требования запуска.

## GitHub Release

Создайте тег **`v3.0.0`** на коммите с этими исходниками. Название выпуска — **Dokvi 3.0.0**. Текст для описания находится в [CHANGELOG.md](../CHANGELOG.md).

Прикрепите:

- `Dokvi-3.0.0.exe` — готовую программу для Windows x64;
- `Dokvi-3.0.0-readme.txt` — руководство;
- `Dokvi-3.0.0-LICENSE.txt` — лицензию MIT;
- `Dokvi-3.0.0-SHA256.txt` — контрольную сумму EXE.

Архив `Dokvi-3.0.0-source.zip` можно приложить дополнительно; GitHub также создаёт архив исходников тега. Тестовый `MD-Reader-Test.exe` не является пользовательским выпуском.

Не помечайте сборку как проверенную на всех системах. EXE пока без цифровой подписи; системные .NET Framework 4.8 и WebView2 Runtime поставляются отдельно. Установщик в этот этап не входит.
