DOKVI 3.0.0

Чтение и редактирование Markdown в Windows.
Автор: TrooSlash, https://github.com/TrooSlash
Поддержать автора: https://tips.tips/000491268

ПЕРВЫЙ ЗАПУСК

Нужны Windows 10 версии 2004 или новее / Windows 11, x64,
.NET Framework 4.8 и Microsoft Edge WebView2 Evergreen Runtime.
Системные компоненты не входят в EXE. Если WebView2 отсутствует,
Dokvi предлагает открыть страницу Microsoft:
https://developer.microsoft.com/microsoft-edge/webview2/

Закройте предыдущую версию Dokvi и запустите Dokvi-3.0.0.exe.
Установка и права администратора для запуска не нужны. Цифровой подписи
издателя пока нет. Установщик в этот выпуск не входит.

Нажмите «Создать» для нового документа или «+» для открытия файлов.
Файлы можно перетащить в окно. «Посмотреть пример» открывает документ
с поддерживаемым форматированием. F1 открывает справку с разделами.

ЯЗЫК И ОФОРМЛЕНИЕ

«⋯ → Язык / Language»: «Как в системе», «Русский» или «English».
Русскоязычная Windows выбирает русский интерфейс, остальные языки
системы выбирают английский. Ручной выбор действует сразу и сохраняется.
Содержимое документов не переводится. Диалоги выбора файлов использует Windows.

В меню «⋯» можно переключить тему.
В Aa можно выбрать размер текста, ширину и положение области чтения.
Граница между исходником и предпросмотром перетаскивается мышью.
Двойной щелчок возвращает соотношение 42 / 58. Прокрутка связана в обе стороны.
Заголовки панелей остаются на месте, пока прокручивается документ.

РЕДАКТИРОВАНИЕ

Ctrl+E переключает чтение и две панели: Markdown слева, результат справа.
«⋯ → Только исходник» оставляет один редактор. Для форматирования выделите
текст и выберите команду в центре верхней панели. Заголовки и списки
применяются к строкам. Повторное нажатие B, I или S снимает оформление.
После вставки ссылки введите адрес в выделенное место. Ctrl+Z отменяет команду.

Enter переносит текст на новую строку. Пустая строка отделяет абзацы,
дополнительные пустые строки сохраняют расстояние. Это особенность отображения
Dokvi: другие программы Markdown могут объединять обычные переносы строк.
Исходный текст при чтении не меняется. В таблицах видны границы столбцов.

Ctrl+P сохраняет PDF с текущим текстом, включая несохранённые изменения.
Для документа с таблицей от 9 столбцов автоматически используется альбомный
A4. Длинные значения переносятся внутри ячеек, выравнивание сохраняется.
Длинные строки кода переносятся в PDF. Большие изображения и схемы
уменьшаются до размера страницы. Формулы переносятся между частями выражения;
цельная формула, например широкая матрица, уменьшается до ширины страницы.
Если изображения ещё загружаются спустя 15 секунд, экспорт прерывается
с сообщением. После загрузки можно повторно нажать Ctrl+P.

Tab добавляет пробелы до следующей позиции с шагом 4. Выделенные строки
сдвигаются вместе. Shift+Tab уменьшает отступ. Чтобы выйти из редактора
к кнопкам с клавиатуры, нажмите Escape, затем Tab.

Предпросмотр обновляется при вводе. Неизменённые изображения, формулы,
диаграммы, раскрытые блоки и прокрутка кода сохраняются при обновлении.
Большой документ может обновляться с задержкой.

ВКЛАДКИ И СОХРАНЕНИЕ

Каждый документ открывается в своей вкладке. Когда вкладки не помещаются,
появляются стрелки прокрутки и список с поиском по имени и пути. Полосу
можно листать колёсиком или тачпадом. Активная вкладка становится видимой.

Ctrl+S сохраняет файл. Для нового документа выберите имя и папку.
Ctrl+Shift+S сохраняет копию в UTF-8. Точка на вкладке отмечает изменения.
Сохранение существующего файла учитывает его кодировку, BOM и окончания строк.
Если файл изменён другой программой, можно сохранить копию, перезаписать
исходник или отменить действие.

При закрытии изменённого документа можно сохранить правки, отбросить их
или отменить закрытие. Новый пустой документ закрывается без вопроса,
в том числе после отмены всего ввода. Пробелы и переводы строк считаются
содержимым. Пустой файл можно явно сохранить через Ctrl+S. Если очистить
уже сохранённый файл, это изменение потребует решения при закрытии.

ВОССТАНОВЛЕНИЕ

Dokvi возвращает открытые вкладки, их порядок, активную вкладку, режим,
место чтения, курсор и несохранённый текст из последней резервной копии.
Копии записываются отдельно от исходных файлов. Ctrl+S нужен для сохранения
в сам файл. Пустые новые вкладки и вкладки, закрытые пользователем,
не восстанавливаются. «Не сохранять» отбрасывает правки.

Запись копии планируется через 550 мс после ввода, при непрерывном наборе
примерно каждые 2 секунды. Эти интервалы не гарантируют завершение записи:
при сбое или отключении питания последние символы могут потеряться.
При обычном закрытии приложение дожидается записи сессии.

Если исходник изменился другой программой, восстановленный черновик
сохраняется отдельно до вашего решения. Если исходник удалён или недоступен,
резервный текст открывается новым черновиком. При повреждении последней
копии используется предыдущая исправная, если она доступна.

Данные находятся в %LOCALAPPDATA%\MD Reader Native:
  session       резервные копии вкладок и черновиков;
  settings.json язык и оформление;
  assets        распакованные ресурсы приложения;
  WebView2      служебные данные движка;
  shell         значок Markdown-файла для Проводника.
Копии хранятся локально, не шифруются Dokvi и не отправляются в сеть.
Версии 2.x и 3.x используют этот же профиль. Настройки версии 1.x не переносятся.

КЛАВИШИ

Ctrl+N             создать документ
Ctrl+O             открыть файлы
Ctrl+W             закрыть вкладку
Ctrl+Tab           следующая вкладка
Ctrl+Shift+Tab      предыдущая вкладка
Ctrl+1…8           выбрать вкладку по номеру
Ctrl+9             последняя вкладка
Ctrl+E             чтение / редактор с предпросмотром
Ctrl+Shift+E       исходник и предпросмотр
Ctrl+S             сохранить
Ctrl+Shift+S       сохранить как
Ctrl+Z             отменить
Ctrl+Y / Ctrl+Shift+Z  повторить
Ctrl+F             найти текст
Ctrl+B             оглавление
Ctrl+R             перечитать файл с диска
Ctrl+P             сохранить PDF
F1                 справка

В справке стрелки влево/вправо переключают разделы, Home/End переходят
к первому/последнему разделу. Esc закрывает справку. Её заголовок, вкладки
и кнопка закрытия закреплены. В «О программе» указаны версия, автор и лицензия.

ФОРМАТЫ И ОГРАНИЧЕНИЯ

Файлы .md, .markdown, .mdown, .mkd и .txt размером до 20 МБ.
UTF-8, UTF-16 LE/BE и Windows-1251 определяются автоматически.
При неверном отображении букв выберите «⋯ → Кодировка».

Поддерживаются заголовки, выделения, списки, таблицы, задачи, сноски,
определения, emoji, индексы, HTML details, метаданные, блоки NOTE/TIP/
IMPORTANT/WARNING/CAUTION, подсветка кода, формулы KaTeX и диаграммы Mermaid.
Формулы и диаграммы работают без интернета. Картинки из интернета требуют
подключения. Локальные картинки и связанные документы доступны из папки
документа и её подпапок; новый документ сначала сохраните в нужную папку.
Расширения Obsidian и MDX могут отображаться обычным текстом.
HTML очищается от скриптов, iframe и встроенных стилей.

ОТКРЫТИЕ ДВОЙНЫМ ЩЕЛЧКОМ

Храните EXE в постоянной папке. В «⋯ → Приложение по умолчанию…» Dokvi
регистрирует свои форматы для текущего пользователя и открывает настройки
Windows. Выберите Dokvi для .md. В Windows 10 может открыться общая страница
приложений по умолчанию: найдите тип файла .md и назначьте Dokvi.
Также можно использовать «Открыть с помощью → Выбрать другое приложение»
в Проводнике. Окончательный выбор делает пользователь средствами Windows.

Поддерживаются ассоциации .md, .markdown, .mdown и .mkd. Обработчик .txt
не меняется. После назначения Dokvi документы получают значок «Плашка MD».
Если EXE перемещён, повторите регистрацию из новой папки.
Регистрация без открытия настроек: Dokvi-3.0.0.exe --register-file-types

ДЛЯ РАЗРАБОТЧИКОВ

Оболочка: C# / Windows Forms / .NET Framework 4.8. Документ и редактор
используют один WebView2 для всех вкладок. Пустое окно нативное; движок
загружается по необходимости и освобождается после закрытия последней вкладки.
Electron и Node.js для запуска не нужны. Потребление памяти при открытом
документе зависит от WebView2 и содержимого, размер EXE его не отражает.

Сборка из исходников и проверенные команды: README.md.
Сценарии тестирования и измерения: docs/development.md.
Установщик в этот выпуск не входит. Его исходники сохранены как прототип.
